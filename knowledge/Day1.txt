3. Pipeline ADAS 

Sensors 
    ↓
Time Sync / Timestamp Alignment (synchronization time for different frequent , timestamp alignment ) -> interpolation to common tick 
    ↓
Coordinate Transform / Ego-motion Compensation (Ego-motion (Vehicle itself) , transform to common vehicle frame )
    ↓
State Estimation: Kalman/EKF (Kalman Filter to make noise deduction ) 
    ↓
Data Association + Track Lifecycle (Assign data to right object, track_id number , use Hungarian algorithm to mapping object to track_id with minimum cost all , track lifecylce of object from tentative -> confirm -> occlusion -> lost data -> deleted)
    ↓
Multi-sensor Fusion (after collect , filter , calibration -> fusion data from multiple sensor -> aggregate information of object , don't choose early fuse cause it really hard , require AI deep , synchronization big issue , expand and error of sensors  ) 
    ↓
Threat Assessment: TTC / Path Prediction (Assess state : Time to collision) 
    ↓
Decision: FCW / AEB (System behavior ) 
    ↓
Warning or Actuation Command 

4. Camera detection model

-> Really robust at : detect class , type of object , accuracy , shape , appearance , .... 
Weak at : Distance , speed , inclement weather
